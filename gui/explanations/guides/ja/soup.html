Soup

Uncond-init ΔW スープ — 新しいアダプタファミリーではなく、単一アーティスト LoRA の品質と堅牢性を高めるレシピです。出力は通常どおりベイク可能な LoRA です (output/ckpt/anima_soup_<target>.safetensors)。

3 つのフェーズ。 (1) 対象(target)を含むアーティストシャードに対して短く行う caption_dropout_rate 1.0 の uncond インタートレイン — 同じシャード内のすべての対象で再利用される、共有された決定論的チェックポイントです。(2) その uncond チェックポイントから初期化したシードごとの N 回のファインチューニング。(3) それらのファインチューニングを network_dim に SVD で切り詰めた正確な ΔW スープ。

得られるもの。 品質向上に加えてシードくじ保険: 3 回分のファインチューニングをスープ化すると、おおよそ最良の単一素材の水準に到達するため、悪いシードを引いてもランを台無しにしなくなります。ランク 16 の SVD 切り詰めはほぼ無料です(エネルギー保持率 ~99.9%)。記憶(memorization)問題の解決策ではありません。

要件。 通常の LoRA チェックポイントのみに対応します(Hydra / Chimera は拒否されます)。uncond プールはファインチューニング用画像と重複してはいけません。対象は必須です — post_image_dataset/resized/ 配下のアーティストディレクトリです。プール・シード・ランクの各項目は妥当なデフォルト値を持っているので、理由がわからなければそのままにしておいてください。1 つのデーモンコマンドジョブとして実行されます(パイプラインが自身で train.py の各フェーズを駆動します)。docs/ と scripts/soup/ を参照してください。
